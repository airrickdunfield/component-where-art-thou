# Privacy policy

JSX Open in Code runs locally during development.

- It listens only on `127.0.0.1:48732`.
- After you explicitly select an inspected element, the browser extension sends
  that element's local source path, line, and column to this companion.
- A locally generated token is required, and only files inside an open VS Code
  workspace can be opened.

JSX Open in Code does not send source code, file paths, browser activity,
analytics, or personal information to a remote server. It does not use telemetry,
advertising, or tracking.
